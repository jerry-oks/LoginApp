# LoginApp
Приложение имитирует вход в аккаунт пользователя и отображает его профиль.

## Стэк
+ Xcode
+ Swift
+ MVC
+ UIKit
+ Storyboard
+ Auto Layout

## Цели и задачи
+ изучение паттерна MVC и различных свойств и методов элементов UI (UITextField, UIButton) 
+ работа с переходами (segue), UITabBarController, UINavigationController, UIAlertController
